# Week 5 – Data Analytics Impact Evaluation and Optimization
Prepared for: Mohit Kumar

This is a reproducible synthetic customer-analytics case study for the Week 5 internship task. It contains 1200 simulated customer records and demonstrates KPI measurement, statistical analysis, segmentation, visualization, impact evaluation and optimization recommendations.

## Files
- `data/customer_analytics.csv` – synthetic dataset
- `analysis.py` – reproducible statistical analysis
- `requirements.txt` – Python dependencies
- `figures/` – generated charts
- `reports/Week_5_Data_Analytics_Impact_Evaluation_Report.docx` – final report

## Important note
The dataset is synthetic and does not represent a real company or real customers. Baseline metrics are calculated from the simulated records. The optimized metrics in the report are modeled planning assumptions, not observed post-intervention results. A real organization should validate causal impact with A/B testing or a controlled rollout.
