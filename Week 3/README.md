# Week 3 – EDA and Visualization Strategy

## Files
- `Week_3_EDA_Visualization_Strategy_Report.docx` – final internship report.
- `Week_3_EDA_Notebook.ipynb` – reproducible EDA notebook.
- `requirements.txt` – Python dependencies.
- `outputs/` – generated charts/tables after notebook execution.

## Dataset
UCI Wine Quality – White Wine:
https://archive.ics.uci.edu/dataset/186/wine+quality

The notebook reads the public white-wine CSV directly from the UCI resource.

## How to run
1. Install Python 3.10+.
2. Run `pip install -r requirements.txt`.
3. Open the notebook in Jupyter/Google Colab.
4. Run all cells from top to bottom.
5. Review the charts and CSV summaries in `outputs/`.
